Unduh Rute GPP

File pemasangan untuk HP Android.

Unduh APK Android
  1. Kalau halaman ini terbuka di dalam aplikasi chat, pilih Buka di Chrome dari menu aplikasi.
  2. Tekan tombol unduh, lalu cek folder Download di HP.
  3. Buka rute-gpp.apk dan pilih Instal.

Pilihan unduh lain

  • Unduh lewat GitHub dengan tombol Download raw file.
  • Unduh ZIP, lalu ekstrak untuk mendapatkan APK.
